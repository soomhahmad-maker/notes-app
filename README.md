# الملاحظات (Notes App)

موقع ملاحظات شخصي يعمل بالكامل في المتصفح ويستخدم `localStorage` كقاعدة بيانات.

## الميزات
- تسجيل حساب / تسجيل دخول عبر البريد الإلكتروني وكلمة المرور.
- كل مستخدم يرى ملاحظاته الخاصة فقط (عزل كامل للبيانات).
- إضافة، تعديل، حذف، تثبيت الملاحظات.
- ألوان للملاحظات، بحث، طوابع زمنية.
- دعم كامل لـ RTL واللغة العربية.
- تصميم احترافي (corporate) متجاوب.

## التشغيل
افتح ملف `index.html` في أي متصفح حديث. لا حاجة لخادم.

## ملاحظة أمنية
هذا تطبيق تجريبي (front-end only). كلمات المرور تُخزَّن مُجزَّأة (hash) في localStorage ولا تُرسل لأي خادم. غير مناسب للإنتاج.
